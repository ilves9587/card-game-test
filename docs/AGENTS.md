# Docs Guide

## Purpose

Use this directory for long-lived reference documentation.

## Put Here

- `design/` product or game design notes
- `superpowers/specs/` approved design specs

## Do Not Put Here

- Implementation plans that belong in `plans/`
- Runtime assets
- Gameplay scripts
